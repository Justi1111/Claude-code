# osu! TikTok edit (mrekk)

Движок, который собирает вертикальный (1080×1920, 60 fps) эдит из osu!-клипов:
сам находит BPM и сильные доли в песне каждого клипа, режет в бит, склеивает
песни переходами и рисует моушн-дизайн — у каждой части свой стиль монтажа.

## Быстрый старт

```bash
pip install -r requirements.txt
python3 make_demo_clips.py      # тестовые клипы (пока нет настоящих)
python3 edit.py --preview       # быстрое превью 540×960 / 30 fps
python3 edit.py                 # финальный рендер -> out/mrekk_edit.mp4 (4 потока)
python3 edit.py --frames 3,7.5  # отдельные кадры в PNG
```

## Как подставить свои клипы

1. Положи файлы в `clips/` (mp4 из osu!/danser/OBS, 16:9, плейфилд по центру).
2. В `edit.json` в `clips` поменяй `file`, а в `parts` — `start` (секунда
   внутри клипа, откуда начинать; притянется к ближайшей сильной доле).
3. Если темп определился не так — `"bpm": 200` у клипа; если склейки не на
   «раз» — `"downbeat_shift": 1` (сдвиг в долях).

## Структура эдита (`edit.json`)

- `hook` — хит-цикл лопается → флеш-нарезка клипов → буквы-вырезки → слово.
  Звук: такты песни первой части перед дропом, фильтр открывается.
- `parts` — части, `style` выбирает язык монтажа (`parts.py`):
  - `record` — красный дуотон, геймплей на качающейся 3D-карточке, счётчик PP,
    стоп-кадр со штампом, пролёт сквозь кадр;
  - `reign` — сплит-скрин из 3 полос (въезжают, меняются, схлопываются),
    счётчик дней, бегущие строки, неон и шлейфы, заикание + нарезка полосами;
  - `trophies` — 3D-карточки с бликом, шквал крупных планов с негативом,
    остановка плёнки;
  - `return` — глухой Ч/Б «#1 потерян» (зачёркивание) → золотой удар
    «#1 снова» → сетка 3×3 → ускоряющаяся нарезка всех клипов.
- `out` — переход в звуке: `sweep`, `stutter`, `tapestop`, `cut`.
- `outro` — геймплей внутри букв, эхо-контуры, глитч в чёрное.
- `voiceover` — реплики поверх музыки (музыка приглушается):
  `{"file": "vo/mrekk1.wav", "at": 1.2, "gain_db": 0}`.
- Звуковые эффекты (свайпы, тики счётчиков, штампы, глитчи) ставятся
  автоматически под анимацию; громкость — `sfx_gain`.

## Модули

- `edit.py` — анализ клипов, таймлайн, звук, параллельный рендер.
- `parts.py` — стили частей. `typo.py` — кинетическая типографика.
- `layers.py` — кадрирование геймплея, 3D-окна, цветокоры, пост-эффекты.
- `gfx.py` — шрифты, спрайты, перспектива. `synth.py` — синтез звука/SFX.

Шрифты в `fonts/` — Google Fonts (SIL Open Font License, см. `fonts/OFL-note.txt`).
