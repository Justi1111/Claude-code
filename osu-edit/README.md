# osu! TikTok edit (mrekk)

Движок, который собирает вертикальный (1080×1920, 60 fps) эдит из osu!-клипов:
сам находит BPM и сильные доли в песне каждого клипа, режет в бит, делает
переходы в звуке между разными песнями и накладывает эффекты и титры.

## Быстрый старт

```bash
pip install -r requirements.txt
python3 make_demo_clips.py      # тестовые клипы (пока нет настоящих)
python3 edit.py --preview       # быстрое превью 540×960 / 30 fps
python3 edit.py                 # финальный рендер -> out/mrekk_edit.mp4
python3 edit.py --frames 3,7.5  # отдельные кадры в PNG
```

## Как подставить свои клипы

1. Положи файлы в `clips/` (любые mp4 из osu!/danser/OBS, 16:9).
2. В `edit.json` у каждого сегмента поменяй `clip` на свой файл и `start`
   на момент (в секундах) внутри клипа, откуда начинать — он сам
   притянется к ближайшей сильной доле.
3. Если темп определился неправильно — добавь подсказку
   `"bpm_hints": {"clips/my.mp4": 200}`; если склейки попадают не в «раз» —
   `"downbeat_shift": {"clips/my.mp4": 1}` (сдвиг в долях).

## Раскадровка (`edit.json`)

- `intro` — замедленное (slowed + reverb) Ч/Б начало с лором.
- `segments` — клипы. `beats` — длина в долях. `out` — переход в следующий:
  `sweep` (песня уходит «под воду» + рывок камеры), `stutter` (заикание бита
  + глитч), `tapestop` (плёнка останавливается), `cut`.
- эффекты сегмента: `reveal_beats` (зум-аут на весь плейфилд), `echo`
  (цветные шлейфы), `jumpcut`, `strobe`, `build` (нарастание), `cam`
  (зум/удар/наклон), `grade` (цветокор), `rgb`.
- `texts` — титры: `slam` (влетающий текст), `type` (печатная машинка),
  `tag` (плашка со статой), `cards` (карточки как в профиле osu!).
  Время в долях сегмента, либо в секундах при `"unit": "sec"`.
- `voiceover` — реплики поверх музыки (музыка приглушается):
  `{"file": "vo/mrekk1.wav", "at": 1.2, "gain_db": 0}` (время — от начала эдита).
