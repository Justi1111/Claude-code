## Сборка

1. Маски человека (Robust Video Matting, ONNX): `RVM_ONNX=<rvm_mobilenetv3_fp32.onnx> python3 -I matte_cam.py <clip> <t0> <t1> <out.npy>`. Нужны три: `really_8_16` (8.0–16.2), `really_16_19` (16.2–19.7), `parents_19_22` (19.0–22.4).
2. Видео: `FT_WORK=<папка с matte/, fonts2/, tracks_x/> python3 -I ending_v3.py out.mp4`. Кадры для проверки: `--frames 62.95,66.8 --stills DIR`.
3. Звук и сведение: `python3 -I ending_v3_audio.py out.mp4 final.mp4`. Трек приглушён в затишье, голос порезан теми же кусками, что и картинка, плюс синтезированные удар, райзер, перелив и бум.

Шрифты: Anton, Instrument Serif Italic, Courier Prime (все SIL OFL), лежат в `fonts/`. Корейская строка набрана Noto Sans KR из `osu-edit/fonts`.
