# Нарисованное интро (0:15.23–0:20.32 трека)

Чисто нарисованная ч/б анимация в стиле референса: туманность, звезда с лучами, разрез с негативом, кольца, полосы, эквалайзеры, печатающийся текст. Видео внутри нет. Длина 5.08 с (305 кадров, 60 fps), последний кадр стоит ровно перед дропом на 0:20.32, дальше идёт основная часть.

Что на что реагирует:
- восьмые (тиканье) — деления на кольце-циферблате, шаги полос, щелчки линии разреза, мерцание звёзд, печать текста, счётчик комбо;
- спектр трека — эквалайзеры по краям и круговой вокруг звезды (как в меню osu!);
- акценты — ударная волна с искажением фона, разлёт частиц, глитч, рывок камеры; звезда-курсор прыгает на следующий круг;
- 0:16.19 и 0:16.51 — серая вспышка, мигание негативом, взрыв частиц;
- 0:19.68–0:20.24 (дробь бочки) — строб на каждую 16-ю, сходящиеся кольца, зум;
- 0:20.24 (тишина) — чёрный кадр, только последний approach circle, который закрывается на дроп.

Рендер: `SONG=<аудио трека> python3 -I geo_anim2.py out.mp4 [seed]`, потом звук: `ffmpeg -i out.mp4 -ss 15.233333 -t 5.083333 -i <аудио> -map 0:v -map 1:a -c:v copy -c:a aac out_with_audio.mp4`.

Шрифты: Noto Serif, Noto Serif JP (только «鮪»), JetBrains Mono — все SIL OFL.
