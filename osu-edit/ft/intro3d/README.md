# 3D-интро для эдита про FlyingTuna

Стилизованная 3D-заставка под интро трека femtanyl — LOVESICK, CANNIBAL! (0:00–0:20.32, до дропа). Персонаж — его чиби в синем капюшоне-тунце: модель собрана из примитивов в three.js, тун-шейдинг и аниме-обводка. Кадры рендерятся в headless Chromium и склеиваются ffmpeg.

## Что происходит и когда (время трека, 189 BPM)

| Время | Что на экране |
|---|---|
| 0:00–0:01.6 | выход из темноты, на 0:00.95 включается прожектор |
| 0:02.5–0:10 | вокруг появляются и лопаются хит-кружки osu! с «300», камера медленно облетает персонажа |
| 0:05.97 | «osu! start / 2016.11.04» (в его голосе на этом месте «2016, November 4th») |
| 0:10.16 | первый сильный удар интро: удар заголовка «FlyingTuna», он машет рукой с лицом «><», вспыхивают звёздочки |
| 0:10.95 | «공중참치» |
| 0:15.2–0:19 | камера наезжает, вспышки на 0:16.19 и 0:16.51 |
| 0:17.51 | «2017.07.23 / #1000» (в голосе «three digits») |
| 0:19.05 | такт «вдоха» перед дропом: шок-лицо, приседает |
| 0:19.5–0:20.0 | прыгает в камеру со speed lines, к 0:20.0 лицо на весь экран |

## Как стыковать с реальным клипом

- Голос: клип «achievement list jumpscare» (08.12.2024) без первых 0.57 с, поставленный на 0:00 трека. Тогда «2016» и «three digits» попадают на надписи.
- Джампскейр: последние 0.27 с того же клипа (0:20.62–0:20.89) встают на 0:20.05–0:20.32, сразу после этого дроп.
- `make_preview.sh` собирает именно так: интро до 0:20.05, потом настоящий джампскейр, потом 2.6 с геймплея 2018 года на дропе.

## Рендер

```
npm i
node render.mjs stills <папка> 6.5,12,19.9 [text=1|0]
node render.mjs video ../../out/ft_intro/tuna_intro_3d_text.mp4 60 20.32 1
node render.mjs video ../../out/ft_intro/tuna_intro_3d_clean.mp4 60 20.32 0
SONG=<аудио трека> ./make_preview.sh
```

`text=0` даёт версию без надписей. Нужен Chromium по пути `/opt/pw-browsers/chromium-1194/chrome-linux/chrome` (поправь в `render.mjs`, если он лежит в другом месте). На CPU (SwiftShader) одна версия считается примерно 25 минут.

Шрифты: Lilita One и Noto Sans KR (только «공중참치»), оба под SIL OFL.
