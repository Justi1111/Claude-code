## Подписи

Рисуются кадрами в `../captions/captions.py` (PIL) и накладываются поверх шота, шрифты в `../captions/fonts` (SIL OFL, урезаны до нужных знаков).

- Майлстоуны: надпись Archivo Expanded Black, белая с лёгким уходом в лаванду, мягкая тень вместо обводки. Появляется в бит чуть крупнее, с коротким расслоением цвета, и садится за 7 кадров. Под ней дата JetBrains Mono, разрядка, золото, между двух тонких линий.
- Плашка #1 в концовке: «세계 1위» (Noto Serif KR Black), золотая линия, «#1 IN THE WORLD» (Montserrat, разрядка) и дата. Внизу слева на мягком затемнении, которое не заходит на вебку и не трогает таблицу ранкинга. Буквы по одной выходят из размытия, линия дорисовывается, через 5.9 с всё медленно уходит.

## Полировка

`../polish/polish.py` проходит по готовому эдиту последним шагом. Майлстоуны он берёт из `cutlist.tsv` рендера основной части.

- На всём: мягкая S-кривая и чуть больше цвета, блум на светлом (кружки, курсор, плашка #1), лёгкая виньетка и мелкое зерно.
- Обычные склейки и дроп без эффектов. Удары только на майлстоунах (726PP, FIRST 800PP, TOP 10, #4, #2): зум +7%, белая вспышка, расслоение цвета, короткая тряска. Такт TABLET без бита — только мягкая вспышка.
- Склейка прямо перед каждым из них на 3 кадра глитчит: полосы кадра съезжают вбок, каналы расходятся.
- Затишье открывается мягкой белой вспышкой, дальше только общий вид, клип топ-1 не трогается.

## Файлы

- `cutlist.tsv` — все 80 нарезок до затишья и клип топ-1 последней строкой: время в треке, длина в ударах, дата и название клипа, точка входа в клип (секунды) и ссылка на Twitch. По нему можно пересобрать нарезку в своём редакторе из исходников.
- `build_main.py` — нарезка 0:20.32–1:11.11 (ffmpeg, кадр в кадр по сетке 60 fps). Входные списки отбора лежали во временной папке сессии, поэтому для повторной сборки нужен только `cutlist.tsv`. Затишье в этом рендере — заглушка, в эдит идут нарезки до 1:00.95. `FT_PLAN_ONLY=1` печатает план нарезки с временем клипов и ничего не рендерит.
- `build_ending.py` — концовка: клип «топ 1» с плашкой (`clip_1.mp4`) и превью концовки с 0:55.87 (с #4).
- `../build_full.py` — весь эдит: интро (`../intro_clip/build_intro.sh`) + нарезки до затишья + концовка, со всем звуком.

Порядок сборки: `build_main.py <work_main>` → `FT_MAIN_WORK=<work_main> build_ending.py <work_end>` → `FT_MAIN_WORK=… FT_END_WORK=… ../build_full.py <full.mp4>` → `FT_MAIN_WORK=… ../polish/polish.py <full.mp4> <final.mp4>` (интро уже собрано в `out/ft_intro_clip/intro_v.mp4`).

Видео (не в git): `out/ft_full_v9/tuna_edit_full_v9_master.mp4` и `..._phone.mp4` — весь эдит с полировкой; без неё — `out/ft_full_v7/`, с ударами на каждой склейке — `out/ft_full_v8/`.
