# Chainsaw Man collage edit

A fan edit of Chainsaw Man in the style of a white-background collage edit (cut-out anime characters floating on
off-white, textured paint strokes, pins, chains, tiny lyric words at the top), cut to the reference's sound.

- `engine/core.py` — skia drawing core: canvas, easing, brush/ribbon strokes, dotted lines, pins, chains, rings,
  blood splatter, speed lines, text, glitch, grain, H.264 writer.
- `engine/fx.py` — treatments for cut-outs: XDoG sketch lines, collage texture fill, paper edge, tint, echoes.
- `engine/timeline.py` — scenes on a beat timeline, post effects, multi-process render, stills and contact sheets.

Footage (official promo videos only: PVs, trailers, creditless OP/EDs), cut-outs and renders live outside git.
