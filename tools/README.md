# Инструменты разработки

Всё здесь — Python 3 без внешних зависимостей. Тесты рассчитаны на локальный
сервер Minecraft Java 26.3 с включённым RCON (`127.0.0.1:25575`, пароль `test`,
см. `rcon.py`) и принудительно загруженной областью `x −16…64, z −16…16`.

| файл | назначение |
|---|---|
| `rs.py` | контейнер раскладки + статический анализатор: кто кого запитывает (правила пыли, повторителей, компараторов, наблюдателей, факелов, рычагов, сильного/слабого питания и квазисвязности выбрасывателей перенесены из исходников 26.3). Каждый источник помечен сетью, каждый приёмник — списком допустимых сетей. |
| `cell.py` | ячейка склада; `chain(n)` — n ячеек с редстоун-блоками вместо секвенсора (для тестов с управлением из Python) |
| `seq.py` | западный торец (генератор, башни, модули линий, вход, рычаг), восточный торец, пол; `warehouse(n)` — весь склад |
| `export.py` | генерирует `datapack/sorter` (4 направления, рекурсивная постройка n ячеек) и файлы структур `structures/*.nbt` |
| `nbt.py`, `nbtread.py` | запись и чтение NBT (файлы структур 26.3: в палитре ключи `id`/`properties`) |
| `docs.py` | генерирует `docs/layers.md` |
| `mc.py`, `rcon.py`, `build.py`, `seqtest.py` | RCON, постройка, чтение состояний, пошаговый прогон с ручными линиями |

Проверка раскладки без сервера:

```
cd tools && python3 -c "import seq, rs; print(rs.Checker(seq.warehouse(3)).run())"
```

Тесты (на сервере, по порядку):

* `t_build.py` — построить склад из 3 ячеек в (0, 20, 0);
* `t_seq.py` — снять осциллограммы шести линий и сравнить с расписанием;
* `t_live.py`, `t_behave.py`, `t_bulk.py`, `t_full.py`, `t_pause.py` — работа в
  реальном времени: сортировка, 5 типов, снятие/новое закрепление, переполнение,
  поток 147 предметов, забитый сундук, пауза;
* `t_rotated.py` — постройка датапаком на юг и проверка;
* `t_structure.py pieces` / `t_structure.py block` — установка без датапаков:
  части через `/place template` и склад из 5 ячеек через блок структур (файлы из
  `structures/` должны лежать в `<мир>/generated/minecraft/structure/`);
* `t_cycle.py`, `t_multi.py`, `t_o2.py`, `t_influence.py` — пошаговые тесты с
  линиями, которыми управляет Python (подменяют выходы секвенсора, после них
  снова запустите `t_build.py`);
* `t_wave2.py` — характеристика волнового лифта (сколько предметов поднимает
  импульс заданной длины).
